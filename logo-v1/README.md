# Nahara's Organization Logo, Version 1

## Summary

1st version of Nahara's Organization Logo. This version is superseded by
[version 2 of the logo](../logo-v2/README.md). This page is kept for historical
purpose.

There are some issues with this version:

- At small scale (e.g. 32x32), the details are being blurred/blended, which
  destroys the important details.
- The area for favicon is actually a rectangle instead of a square.
