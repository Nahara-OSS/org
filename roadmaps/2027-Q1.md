## Nahara's Motion

If everything went well in Q4 2026, this is when we begin porting Nahara's
Motion to other runtime/framework. There are some worthy options to consider:

| Target   | Language  | Vulkan?            | Plugin support   | Note                 |
| -------- | --------- | ------------------ | ---------------- | -------------------- |
| Avalonia | .NET (C#) | **Yes**            | Assembly loading |                      |
| Qt       | C++       | **Yes**            | Qt plugin        |                      |
| egui     | Rust      | **Yes** (wgpu-hal) | FFI              | Bad styling support? |
| Web      | JS        | No                 | Dynamic import   |                      |
| Compose  | Kotlin    | **Yes?** (Skia)    | Class loader     |                      |

We do have plan to pick Avalonia, but there are several rounds of evaluation
ahead before we actually commit to one framework for multiple apps, but in
general, we are looking for runtime or framework for building desktop app that
satisfy the following requirements:

- Support embedding Vulkan/OpenGL as UI widget;
- Plugin support;
- Styling support (we are not interested in "native widgets", as we have our own
  UI design and UX guidelines).
